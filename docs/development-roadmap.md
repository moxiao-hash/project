# StudyPilot 开发路线

本项目以短迭代推进。每个迭代都必须具备：目标、失败测试、最小实现、可复现验证与简短复盘。

## 阶段 0：项目基线

- [x] 产品需求与 MVP 范围
- [x] 单仓库目录和职责边界
- [ ] Git 首次提交与远程推送
- [ ] Java 项目基线测试通过

## 阶段 1：传统学习管理核心

1. 学习目标：创建、查询、输入校验与领域测试。
2. 学习计划：为目标创建计划草案与确认状态。
3. 每日任务：创建、完成、跳过、延期。
4. 用户账户与数据隔离。
5. MySQL 持久化、迁移与接口测试。
6. Vue 工作台：目标、计划和今日任务的最小界面。

## 阶段 2：资料与 AI 基础

1. 资料上传与异步处理状态。
2. FastAPI 服务骨架与内部认证。
3. 云端模型 API / Ollama Provider 抽象。
4. 资料检索、联网检索与来源展示。
5. 流式 Agent 对话与简洁执行状态。

## 阶段 3：自适应学习 Agent

1. Agent 生成计划草案，用户确认后写入。
2. 基于资料与知识点生成选择题。
3. 记录作答和掌握度。
4. 打卡触发与夜间兜底的计划调整。
5. 授权策略、审计记录、计划版本和撤销。

## 阶段 4：工程化与发布

1. Redis、异步任务与限流。
2. 向量库与资料处理队列。
3. Docker Compose、环境样例和健康检查。
4. 自动化测试、Agent 评测集和可观测性。
5. 公网演示环境、演示数据与录屏。
6. 可选：本地模拟旧系统 + Playwright GUI 兜底演示。

## 每次功能迭代的固定流程

1. 明确一个用户可见行为与验收条件。
2. 先写一个失败的单元或接口测试。
3. 完成最小实现，不提前建设下一阶段能力。
4. 在本机执行测试并由学习者手动验证。
5. 记录完成内容、未覆盖边界与下一步。
