# StudyPilot 部署与演示指南

本文覆盖阶段 8 的本机原生启动、Docker Compose 启动、演示数据和五分钟演示路线。
StudyPilot 当前定位为单机、单 FastAPI 进程的个人学习应用。

## 1. 安全配置

三个服务端密钥必须在首次部署时生成并保存到密码管理器或安全的部署环境中：

```bash
# Java 与 Python 共用；不要使用示例值
openssl rand -hex 32

# Java 加密用户 DeepSeek/Tavily Key
openssl rand -base64 32

# Python 加密 LangGraph 会话和 SQLite 元数据
openssl rand -base64 32
```

分别填入：

```text
INTERNAL_SERVICE_TOKEN
AI_CREDENTIAL_MASTER_KEY
LANGGRAPH_AES_KEY
```

`AI_CREDENTIAL_MASTER_KEY` 和 `LANGGRAPH_AES_KEY` 必须长期稳定。前者变化后，MySQL
中已保存的用户 Key 无法解密；后者变化后，已有 Agent 会话无法恢复。不要把任何真实
值提交 Git。DeepSeek 和 Tavily Key 优先由登录用户在“AI 设置”中提交给 Java；本地
开发也可以使用服务端环境变量作为回退。

## 2. 原生启动

启动顺序为 MySQL → Java → FastAPI → Vue。默认端口：

| 服务 | 端口 | 健康检查 |
|---|---:|---|
| MySQL | 3306 | `mysqladmin ping` |
| Spring Boot | 8080 | `/actuator/health` |
| FastAPI | 8000 | `/health` |
| Vite | 5173 | 页面可访问 |

Java 可以在 IDEA 中运行 `StudyPilotApplication`。启动前通过 Run Configuration
设置数据库连接、`INTERNAL_SERVICE_TOKEN`、`AI_CREDENTIAL_MASTER_KEY` 和
`STUDYPILOT_AI_SERVICE_BASE_URL=http://127.0.0.1:8000`。

FastAPI：

```bash
cd ai-service
cp .env.example .env
# 编辑 .env；确保 INTERNAL_SERVICE_TOKEN 与 Java 相同，
# LANGGRAPH_AES_KEY 稳定且 AGENT_WORKER_COUNT=1。
.venv/bin/python -m uvicorn app.main:app --port 8000
```

不要使用 `--workers 2` 或启动第二个 FastAPI 进程。加密 SQLite 与本地 Qdrant
是单进程部署，第二个进程会被文件锁拒绝。

Vue：

```bash
cd web
npm ci
npm run dev
```

开发环境必须使用真实 HTTP gateway。浏览器只访问 Java `/api/**`，不得保存或发送
内部服务令牌，也不得直连 Python `/internal/**`。

## 3. Docker Compose

```bash
cp infra/.env.example infra/.env
# 填写 MySQL 密码和上文生成的三个稳定密钥
docker compose --env-file infra/.env -f infra/docker-compose.yml up --build
```

打开 `http://localhost:5173`。Nginx 把同源 `/api` 和 `/actuator` 请求代理到 Java；
Python 内部端口不暴露给浏览器。命名卷保存：

- MySQL 业务数据；
- 加密 Agent SQLite；
- 本地 Qdrant 索引；
- Hugging Face 与 FastEmbed 模型缓存；
- 可选 Prometheus 数据。

停止容器不会删除数据：

```bash
docker compose --env-file infra/.env -f infra/docker-compose.yml down
```

只有明确需要清空整套本地演示数据时才考虑 `down -v`；它会删除上述命名卷。当前开发机
如果没有 `docker` 命令，就只能验证 Compose 配置和自动化契约，不能声称容器实跑成功。

## 4. 演示数据

Java 与 FastAPI 启动后执行：

```bash
DEMO_PASSWORD='临时强密码' \
STUDYPILOT_BASE_URL=http://127.0.0.1:8080 \
scripts/demo-data.sh
```

脚本通过公开 Java API 创建唯一演示账户、学习目标和一份短大纲。它不会调用内部 API，
也不会打印密码、Bearer Token 或 API Key。输出邮箱、目标 ID 和资料 ID；资料随后由
FastAPI 异步解析。

完整公共 API 验收见
[`stage8-release-e2e.http`](stage8-release-e2e.http)。该文件使用 IntelliJ 变量，不含
真实凭据。

## 5. 五分钟演示路线

### 5.1 经典业务能力演示
1. 注册并登录，展示工作台和目标。
2. 在 AI 设置中展示“服务器回退/用户配置”状态；强调 Key 不回显。
3. 导入演示大纲，等待 `READY`，在知识问答中展示带定位的资料引用。
4. 创建计划会话，多轮补齐时间约束，展示 `DRAFT_READY` 表单；修改后用专用确认接口保存。
5. 在今日任务中生成“完成任务”预览；说明普通对话不能授权写操作，再点击确认并展示审计。
6. 从任务生成五题测验，提交选择题和代码文本，展示异步 AI 评分、掌握度和薄弱点任务。
7. 重启 FastAPI，按原 `conversationId` 打开会话，证明加密 SQLite 可以恢复上下文。

### 5.2 Agent 原生全链路演示 (Task 26)
1. 打开统一 Agent 首页 `/assistant`，查看路线未完成节点与今日待办建议。
2. 发送自然语言指令（如“继续完成 Spring Boot 练习”），触发白名单 UI Action 导航至对应节点。
3. 触发高风险写操作（如更新设置、调整计划或生成测验），检查前端生成的 `WAITING_CONFIRMATION` 受治理动作卡。
4. 验证普通聊天输入“我确认”不会生效，只有点击卡片上的确认按钮调用 `/confirm` 专用接口后状态才转为 `SUCCEEDED`。
5. 查看 SSE 流式事件流（`/api/assistant/conversations/{id}/events`），验证包含递增 `sequence` 并在断线后使用 `Last-Event-ID` 正常重放。
6. 启动 Local Runner 并通过 `/api/runner/preview` 与 `/api/runner/executions` 执行只读与高风险构建测试，验证断网隔离容器执行。
7. 打开“AI 助手 → 运行健康”页面（`/assistant/health`），查看个人执行成功率、待确认动作数与 Token/成本统计。

## 6. 简历描述

> 独立设计并实现 Java Spring Boot + FastAPI + Vue 的 AI 学习执行工作台：以 Java
> 作为认证、业务事实和授权审计边界，通过 LangGraph 编排多轮计划、RAG 知识问答、
> 任务操作与自适应测验；实现来源引用、确定性确认、幂等执行、AES-GCM 用户 Key
> 托管、加密 SQLite 会话恢复、Qdrant 混合检索及 Docker Compose 单机交付。
> 全面演进为 Agent 原生架构，实现四层信任边界隔离、统一 SSE 会话流式推进、受治理
> 动作卡与白名单 UI Action 调度、独立 Local Runner 容器化沙箱与 Developer Agent 安全受控工作流。

面试时应同时说明安全取舍：浏览器不接触内部令牌；高风险写操作必须预览和专用确认；
模型输出经过结构校验；编程题只做文本评估，不执行不可信代码。Local Runner 执行在断网只读容器内，
Git commit 与 push 相互独立且均为高风险专用确认动作。

## 7. 已知限制

- LangGraph SQLite 与本地 Qdrant 只支持单 FastAPI 进程，不支持横向扩容。
- 业务页面当前支持普通 JSON 与统一 Assistant SSE 流式响应混合运行。
- 不支持扫描 PDF OCR、图片理解、Ollama、本地敏感资料生成测验。
- 不含教师/管理员、多用户协作和 GUI 键鼠兜底。
- 编程题不编译、不运行，仅提供 `AI_EVALUATED` 文本反馈；代码工程测试必须经由受治理的 Local Runner 执行。
- Local Runner 依赖本机 Docker/Podman，未安装容器引擎时直接拒绝执行，绝不退回宿主机。
- 全仓代码测试与 Ruff lint 检查已全量通过。
