# StudyPilot 协同开发交接说明

本文档是多个 Agent（Codex、ZCode、DeepSeek Harness 等）交替开发时的统一交接入口。任何开发者开始工作前，应先阅读本文档、对应实施计划和最近提交；结束一个小步骤时，应同步更新本文档，避免只在对话中留下关键信息。

## 固定交接规则

每个 Task 或可独立验证的小步骤都必须记录：

1. 当前状态：`未开始 / 开发中 / 已完成 / 被阻塞`。
2. 已实现范围及明确未实现范围。
3. 关键代码入口和重要设计取舍。
4. 新增或修改的数据库、接口、配置及安全边界。
5. 已执行的测试命令、测试结果和已知限制。
6. 对应 Git 提交号，以及未提交文件的归属和原因。
7. 下一位开发者可以直接执行的下一步。

生产代码继续遵循：先写失败测试、实现最小代码、局部验证、全量验证、更新文档、独立提交并推送。
