# StudyPilot 系统架构

> 状态：阶段 8 本地发布基线，2026-07-29。

## 1. 单仓库边界

```text
┌───────────────┐
│ web           │  Vue 3 学习工作台、计划表单、对话与执行记录
└───────┬───────┘
        │ HTTPS / JSON，仅访问 /api/**
┌───────▼───────┐
│ backend       │  Spring Boot：身份、公共门面、授权、业务事实、审计
└───────┬───────┘
        │ /internal/**，高熵共享服务令牌
┌───────▼───────┐
│ ai-service    │  FastAPI：RAG、模型路由、LangGraph、工具编排
└───┬────────┬──┘
    │        │
DeepSeek/  Qdrant + 加密 SQLite
Tavily
```

MySQL 是核心业务的规范数据源。Qdrant 是可以从 MySQL 资料块重建的派生索引；
加密 SQLite 保存 Agent Checkpoint、会话元数据和可恢复快照。

## 2. 服务职责

### `backend/`

后续采用按业务领域组织的模块化单体，而不是一开始拆微服务：

```text
user/       账户、用户设置和数据隔离
learning/   学习目标、计划、任务、进度与版本
material/   资料元数据、处理状态与来源策略
assessment/ 知识点、题目、作答与掌握度
agent/      授权记录、执行任务、操作审计和 Java 工具 API
shared/     异常、认证、时间、分页等跨领域能力
```

Spring Boot 负责所有写业务数据的决策。浏览器的 Agent 请求先进入已认证的
`/api/agent/**` 公共门面，由 Java 从 Bearer Token 派生 `ownerId`，再调用 Python。
前端不能提交 `ownerId`，也不能接触内部服务令牌。任何 Agent 写入都必须经过用户身份、
授权范围、参数校验、乐观锁和审计。

### `ai-service/`

FastAPI 负责变化较快的 AI 编排：资料解析、混合检索、模型路由、计划草案、测验生成
和工具调用循环。它通过受控 Java API 读取或请求业务操作，绝不直连 MySQL 写入核心
数据。会话使用 `AsyncSqliteSaver` 和应用级加密持久化；本地部署只允许一个进程。

### `web/`

Vue 负责响应式交互。`services` 层统一调用 Java 公共 API；Agent 页面在 URL 保存
`conversationId`，刷新后使用 GET 恢复。它显示引用、降级警告和执行状态，不展示模型
内部推理，不把模型常识伪装成资料或联网来源。

### `infra/`

保存 Docker Compose、Nginx 同源反向代理、环境变量样例、健康检查、Prometheus 和
部署说明。MySQL、Agent SQLite、Qdrant 和模型缓存都使用命名卷。

## 3. 关键架构约束

1. **API 优先**：Agent 首选调用 Java 的结构化工具 API；GUI 自动化仅预留适配器，作为后续受控兜底。
2. **确认后写入**：首次计划由对话生成草案，用户通过结构化表单确认后才写入业务库。
3. **可审计执行**：自动调整计划、生成内容和失败结果均需持久化执行记录。
4. **可撤销变更**：计划调整保存版本与差异，高风险变更需确认。
5. **隐私路由**：资料隐私级别决定云端 API、本地 Ollama 或脱敏处理路径。
6. **幂等任务**：同一计划、日期和触发原因不能重复成功调整，防止打卡触发与夜间检查重复执行。
7. **秘密最小暴露**：用户模型 Key 在 Java 使用 AES-GCM 加密，浏览器只看配置状态和
   脱敏尾号；日志过滤凭据和授权头。
8. **单进程约束**：本地 SQLite 与 Qdrant 依赖进程锁；横向扩容前需迁移到共享存储。

## 4. 已实现闭环

```text
登录 → 目标 → 计划 Agent 草稿/修订/确认
→ 任务 Agent 预览/确认/审计
→ 资料解析 → RAG/联网问答与引用
→ 自适应测验 → 异步代码文本反馈 → 掌握度/复习任务
→ FastAPI 重启后恢复会话
```

当前响应为普通 JSON；SSE、OCR、Ollama、多人协作、真实代码执行和分布式部署属于后续
演进范围。启动和演示见[部署与演示指南](部署与演示指南.md)。
